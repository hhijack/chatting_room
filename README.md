# 聊天室项目

这是一个简单的Java聊天室应用，包含服务器端和客户端。它支持用户认证、消息广播、私聊、在线用户列表查看等功能。

## 功能特性

- 用户认证：通过用户名和密码登录
- 实名聊天：用户以真实用户名发送消息
- 匿名聊天：用户可以选择匿名模式发送消息（功能待实现）
- 消息广播：发送的消息会广播给所有在线用户
- 私聊：可以向特定用户发送私聊消息
- 在线用户列表：查看当前在线的用户
- 系统命令：支持一些系统命令（如列出在线用户、退出等）

## 项目结构

- `ChatServer.java`: 服务器端主类，负责管理用户连接、验证用户身份、转发消息、记录日志
- `ChatClient.java`: 客户端主类，负责用户界面和与服务器的通信
- `ClientHandler.java`: 处理单个客户端连接的类，包括认证、消息收发等
- `README.md`: 项目说明文档
- `users.txt`: 用户数据库文件，存储用户名和密码
- `server_log.txt`: 服务器日志文件

## 如何运行

1. 编译所有Java文件
2. 启动服务器端：运行 `ChatServer` 类
3. 启动客户端：运行 `ChatClient` 类
4. 在客户端输入用户名和密码进行登录
5. 使用系统命令和聊天功能进行交互

## 系统命令

- `list`: 查看当前在线用户列表
- `quit`: 退出聊天室
- `showanonymous`: 显示当前聊天方式（实名或匿名）
- `anonymous`: 切换到匿名聊天模式（功能待实现）

## 匿名聊天功能

匿名聊天功能目前尚未完全实现。计划中的实现包括：
